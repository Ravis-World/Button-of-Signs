# Button of Signs (that don't shape your future)

A small pixel-art roguelike game about ignoring advice. Each room gives you three doors
and a randomly chosen sign. The sign might tell you to open or avoid a door,
claim one is safe or locked, point to the exit, or even warn that every door is
a trap. Figure out how to disobey it and make your way through 20 rooms.

Sign types, the door a sign refers to, and door colors are randomised each
room. Some sign types can repeat.

## Controls

- **A / Left Arrow** — select the previous door
- **D / Right Arrow** — select the next door
- **1, 2, 3** — choose a door directly
- **Enter / Space** — choose the selected door
- **R** — restart after a game over or victory

## Run from source

The project includes the DOME runtime for Windows. From the project folder,
run:

```powershell
cd src
..\lib\dome-windows-x64\dome.exe main.wren
```

## Build a standalone executable

Run `export.bat` from the project folder. It bundles the Wren source with DOME
and creates `dist\ButtonOfSigns.exe`.

## Project layout

- `src\main.wren` — game loop, controls, and drawing
- `src\room.wren` — randomised room, sign, and door logic
- `src\door.wren` — door data
- `src\game.egg` — bundled game source generated by DOME
- `lib\dome-windows-x64\dome.exe` — DOME runtime and bundler
